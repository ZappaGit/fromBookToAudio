# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussions on the technical merits, and do not harass anyone.

To report a concern, contact the maintainer privately through GitHub ([@ZappaGit](https://github.com/ZappaGit)). Security issues go through [SECURITY.md](SECURITY.md).
